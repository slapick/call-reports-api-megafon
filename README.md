# Коннектор Инфопанели: телефония Мегафон

Выгружает данные виртуальной АТС Мегафон:
- **Мегафон ВАТС 2.0** (`simple-api.cp.megafon.ru` и `data-api.cp.megafon.ru`, авторизация JWT-токеном);
- **Мегафон ВАТС 1.0 legacy** (`api.megapbx.ru`, CRM API v1).

Построен на SDK [infopanel-connect](https://gitlab.itgrn.ru/infopanel/connector-sdk).

| Сущность | Метод API (ВАТС 2.0) | Метод API (ВАТС 1.0) | Связь |
|---|---|---|---|
| `calls` — звонки | JSON-RPC 2.0 `get.mgf_calls` | `GET /crmapi/v1/history/json` | `operator_login` → `operators.login` |
| `operators` — сотрудники | `GET /employee` | `GET /crmapi/v1/users?with=status` | `login` |
| `groups` — отделы | `GET /employee-group` | `GET /crmapi/v1/groups` | `id` |
| `group_members` — состав отделов | `GET /employee-group` + `/employee` | `GET /crmapi/v1/groups` (`users[]`) | `group_id` → `groups.id`, `login` → `operators.login` |

Период датасета передаётся в API (`date_from`/`date_till` в ВАТС 2.0 или `start`/`end` в ВАТС 1.0); без периода выгружаются последние 30 дней.

```
megafon_connector.py   коннектор (класс MegafonConnector)
megafon_templates.py   готовые датасеты, виджеты, дашборды и быстрый старт
tests/                 тесты (API подменяется примерами ответов)
requirements.txt       зависимости: infopanel-connect>=2.6.0,<3
requirements-dev.txt   + pytest
Dockerfile             образ сервиса
.github/workflows/     CI: тесты на Python 3.10–3.12 и сборка образа
```

## Колонки

### `calls` — Звонки

| Колонка | Тип | Описание |
|---|---|---|
| `id` | string | ID звонка |
| `date` | datetime | Дата и время начала |
| `direction` | string | Направление (in/out) |
| `direction_name` | string | Направление |
| `status` | string | Статус (success/missed/noanswer) |
| `status_name` | string | Статус |
| `client_number` | string | Номер клиента |
| `diversion` | string | Номер ВАТС, по которому пришёл звонок |
| `telnum_name` | string | Имя номера ВАТС |
| `destination` | string | Адресат входящего звонка |
| `operator_login` | string | Логин сотрудника |
| `operator_name` | string | Сотрудник |
| `group_name` | string | Отдел |
| `wait` | number | Ожидание на линии, сек |
| `duration` | number | Длительность разговора, сек |
| `record_url` | string | Ссылка на запись разговора |
| `rating` | number | Оценка качества обслуживания |
| `note` | string | Примечание |
| `missed_status` | string | Статус пропущенного звонка |
| `client_phone` | string | Номер клиента — *вычисляется* |
| `is_inbound` | boolean | Входящий — *вычисляется* |
| `is_answered` | boolean | Разговор состоялся — *вычисляется* |
| `is_missed` | boolean | Пропущенный входящий — *вычисляется* |
| `answered_percent` | number | Разговор состоялся, % (100/0) — *вычисляется* |
| `missed_percent` | number | Пропущенный входящий, % (100/0) — *вычисляется* |
| `minutes` | number | Длительность разговора, мин — *вычисляется* |
| `hour` | string | Час начала по времени АТС («09:00») — *вычисляется* |
| `weekday` | string | День недели по времени АТС («1 Пн» … «7 Вс») — *вычисляется* |
| `has_recording` | boolean | Есть запись разговора — *вычисляется* |
| `is_internal` | boolean | Внутренний звонок — *вычисляется* |

Вычисляемые колонки нужны для готовых отчётов и дашбордов:

- `client_phone` — номер собеседника вне АТС (у внутренних звонков пустой).
- `is_answered` — разговор состоялся (`status == "success"`).
- `is_missed` — пропущенный входящий звонок (`is_inbound` и `status != "success"`).
- `answered_percent` и `missed_percent` — те же признаки в виде 100/0: их среднее значение даёт корректную долю в процентах (25 → «25%») в формате `percent` Инфопанели.
- `hour` и `weekday` рассчитываются по времени АТС (по умолчанию московское время).

## Готовые датасеты, виджеты и дашборды

Описаны в `megafon_templates.py` (формат — `docs/templates.md` в connector-sdk).
Пользователь выбирает их в галерее Инфопанели и сразу видит свои данные.
**Быстрый старт** при установке из маркетплейса создаёт источник и дашборды
«Пульс дня» и «Итоги месяца».

Во всех датасетах, кроме «Активности сотрудников», внутренние звонки исключены
(`is_internal ≠ true`). Доли (пропущенных, дозвона) — среднее колонки `missed_percent` или
`answered_percent` (100/0), поэтому значение сразу в процентах.

### Датасеты (15)

| id | Название | Период | Что внутри |
|---|---|---|---|
| `calls_today` | Звонки сегодня | сегодня | звонки, разговоры, пропущено, минуты, доля пропущенных; по часам, типам, сотрудникам |
| `callback_today` | Перезвонить сегодня | сегодня | номера с пропущенным и без разговора; список пропущенных звонков |
| `outbound_today` | Обзвон сегодня | сегодня | исходящие, дозвоны, доля дозвона — по сотрудникам и часам |
| `calls_week` | Звонки за 7 дней | 7 дней | итоги и ряды по дням: звонки, пропущенные, минуты |
| `calls_month` | Звонки за месяц | этот месяц | итоги, по дням, сотрудникам, результатам; пятёрка лидеров, кто пропускает |
| `calls_last_month` | Звонки за прошлый месяц | прошлый месяц | итоги закрытого месяца для сравнения |
| `inbound_month` | Входящие за месяц | этот месяц | принято, пропущено, доля пропущенных по дням, по статусам и линиям |
| `missed_month` | Пропущенные за месяц | этот месяц | по дням, часам, дням недели, линиям, сотрудникам; полный список |
| `lines_month` | Многоканальные номера за месяц | этот месяц | звонки, клиенты, пропущенные по номерам — отчёт по рекламным каналам |
| `load_30_days` | Нагрузка по часам и дням недели | 30 дней | звонки по часам, дням недели и таблица «день × час» |
| `outbound_month` | Исходящие за месяц | этот месяц | попытки, дозвоны, доля дозвона, «дозвонились или нет», средний разговор; разговоры до 10 секунд |
| `employees_month` | Сотрудники за месяц | этот месяц | рейтинг, доля пропущенных и средний разговор по сотрудникам |
| `departments_month` | Отделы за месяц | этот месяц | звонки, разговоры, пропущенные, минуты по отделам |
| `employee_activity` | Активность сотрудников за 30 дней | 30 дней | все сотрудники АТС и их звонки; кто без звонков |
| `clients_month` | Клиенты за месяц | этот месяц | уникальные номера, потерянные клиенты, кто звонит чаще всех |

**«Перезвонить» и «потерянные клиенты».** Звонки группируются по `client_phone`.
Номер попадает в список, если у него есть пропущенный входящий и нет ни одного
состоявшегося разговора за период, ни входящего, ни исходящего. Как только
клиенту перезвонили и поговорили, номер из списка пропадает.

**«Активность сотрудников»** строится от `operators` со связью на `calls`, чтобы
в отчёт попали и сотрудники без звонков. Период у связанного набора не задаётся,
поэтому звонки берутся за 30 дней по умолчанию коннектора.

## Запуск без Docker

```bash
pip install -r requirements.txt \
  --index-url https://gitlab.itgrn.ru/api/v4/projects/infopanel%2Fconnector-sdk/packages/pypi/simple \
  --extra-index-url https://pypi.org/simple
infopanel-connect check megafon_connector:MegafonConnector --secrets secrets.json  # {"api_key": "<ключ>"}
INFOPANEL_SIGNING_SECRET=dev infopanel-connect serve megafon_connector:MegafonConnector --port 8090
```

Тесты: `pip install -r requirements-dev.txt` (с тем же `--index-url`), затем `pytest -q`.

Для правок SDK одновременно с коннектором: `pip install -e ../connector-sdk`.

## Docker

```bash
docker build -t call-reports-api-megafon .
docker run --rm -p 8090:8090 -e INFOPANEL_SIGNING_SECRET=dev call-reports-api-megafon
curl http://localhost:8090/health
```

## Подключение источника

- **Домен АТС Мегафона** — по умолчанию `simple-api.cp.megafon.ru` (для ВАТС 2.0); для ВАТС 1.0 укажите `api.megapbx.ru`;
- **Ключ для авторизации в АТС** — из личного кабинета Мегафона (Интеграция с CRM → API → «Сгенерировать ключ»).
